# 指标、口径、评分和缺失处理

模型 `qilu-hit-v0.1`，**探索性启发式规则**。权重、阈值、覆盖标准和观察期是本版工作假设；没有随机样本、样本外回测或概率校准。不得声称来自“100个独立游戏验证”。

## 1. 五组不是五个标签，而是15个可审计输入

| 维度 | 满分权重 | 评分输入（括号内为总分权重） | 同时采集、不直接计分 |
|---|---:|---|---|
| G 增长 | 30 | 七日CCU倍数(15)、日低位抬升(5)、周访问净增倍数(5)、周收藏净增倍数(5) | 当前/中位CCU、样本覆盖、峰值、票数、好评率、事件、投放 |
| C 玩法与内容 | 25 | 核心循环(8)、重复游玩深度(8)、设计差异(9) | 实体去重数量、近14天新增、首奖励耗时、不同场景/局次 |
| D 决策与参与 | 15 | 实际决策深度(8)、玩家参与证据(7) | 问题类别、去重参与者、合作/挑战/分享样本 |
| V 传播 | 20 | 七日独立创作者(7)、新视频周倍数(6)、匹配视频首24h播放速度倍数(4)、可传播瞬间(3) | 新视频样本、格式、头部集中度、推广标记 |
| U 更新 | 10 | 14天有效内容更新数(3)、更新后基线倍数(7) | 新实体/新任务/新问题、活动/促销混杂因素 |

Google搜索词数量和竞争不在上表。它们回答“网站能承接什么”，不能证明游戏会不会爆。

## 2. 数据状态

数值字段用如下状态：

- `observed`：直接看见的值或按档位编码的具体观察，有引用。
- `derived`：按固定公式计算，有输入与窗口。
- `unknown`：尚不能知道；不是0。
- `not_collected`：还没执行采集，必须解释原因。
- `unavailable`：尝试后不可获得。
- `partial`：范围截断、估读、口径不齐，不能当完整输入。
- `conflicting`：来源存在未解决冲突。
- `stale`：已过适用期，未刷新。
- `not_applicable`：如预上线没有更新效果。仍作为缺失保留分数界限，不偷偷分摊成完整100分。

只有前两种可以填非null值。其他状态的已观察样本放`diagnostics`，评分`value=null`。有限检查后没看见某机制，一般是未知，不是证实不存在。

## 3. 历史与时间口径

统一UTC。设截止日为T，当天未结束的小时不进入完整日指标。最新比较日为T-1，对照为T-8。

1. 同小时内多次CCU先取中位数；每小时等权，防止活动时采样加密造成虚高。
2. 一天至少18个不同小时桶、连续缺失不超过4小时，才计算日中位数与P20。否则日指标null。该标准是v0.1采样规则，不是平台标准。
3. 用真实日期对齐，不把最近一个有数据的日子偷偷替代缺失对照日。
4. 7日比较两天都必须有效。基期0、历史不足、来源混杂、不可复核曲线不计算倍数。
5. P20为有效小时桶值的第20百分位，线性插值；它叫“日低位代理”，不是全日最低人数。
6. Visits/Favorites使用T、T-7、T-14的边界快照做差。允许每个边界±2小时，两个窗口时长差不超过2.5%，并记录实际时间。没有边界不拿累计总量替代净增。
7. 计数下降先调查取消收藏、数据回滚或口径变化。脚本保守输出unknown并保留净变化，不能直接称作弊或跌没了。
8. 缺分母不加1凑除法，不把10→100和2000→20000视作同等市场规模，绝对规模单独展示。
9. 同龄分位数只有真实可比候选池时才报告：公布池大小、年龄桶、类型、采样与日期；没有池不宣称“前10%”。v0.1不把未经校准的分位数加入默认分数。

### G的四个公式

```text
ccu_g7 = median_CCU(T-1) / median_CCU(T-8)
ccu_floor_g7 = P20_CCU(T-1) / P20_CCU(T-8)
visits_accel7 = [Visits(T)-Visits(T-7)] / [Visits(T-7)-Visits(T-14)]
favorites_accel7 = [Favorites(T)-Favorites(T-7)] / [Favorites(T-7)-Favorites(T-14)]
```

Votes、收藏/访问之比只作诊断，不等同满意度、转化率或留存；API Visits并非独立访问者。游戏后台D1/D7、DAU、收入等只有已获授权才使用。

## 4. 数值指标的确定性档位

表格中各门槛使用“达到或超过”；取满足的最高档位，不做主观微调。查不到则不进入此表。

| 输入 | 原始值→分数（0–100） |
|---|---|
| ccu_g7 | 0→0；0.5→10；1→30；1.5→45；2→60；3→75；5→90；8→100 |
| ccu_floor_g7 | 0→0；0.5→15；1→40；1.2→60；1.5→80；2→100 |
| visits_accel7 / favorites_accel7 | 0→0；0.5→15；1→40；1.5→65；2→85；3→100 |
| yt_creators7 | 0→0；1→15；3→30；5→45；10→60；15→75；30→90；50→100 |
| yt_videos_g7 / yt_velocity_ratio | 0→0；0.5→15；1→40；1.5→65；2→85；3→100 |
| content_updates14 | 0→0；1→60；2→80；3→90；4→100 |
| post_update_baseline | 0→0；0.5→15；1→40；1.2→65；1.5→85；2→100 |

“3倍/5倍、15/30频道”承接旧报告的初筛思路，细化档位和新权重是本次设计。它们不是显著性结论，不是一定要凑齐的门槛。

**视频口径**：

```text
yt_creators7 = 最近7天采集范围内，经核实与本游戏有关的非官方独立频道数
yt_videos_g7 = 最近7天去重新视频数 / 前7天去重新视频数
yt_velocity_ratio = 新一批匹配视频的首24h播放速度中位数 / 前一批匹配视频对应中位数
```

同名误匹配、官方广告、搬运另记，不能假装独立自然传播。两周必须同样查询策略、分页及范围。任一窗口截断导致不可比则`partial`。频道总量是声明范围内观察，不是全网总量。

速度样本每批至少5条匹配且确有首24h快照；此最小量仅是防单条主导的v0.1质量线，不能视为统计充分。快照容差±2小时，记录真实观察时长并分别除以时长；两批格式和频道量级尽量匹配。未满24小时视频不能比较成熟24h表现。无匹配样本则null。

**更新口径**：

`content_updates14`只计近14个完整UTC日中已发布、改变玩法内容或目标的去重版本。仅改公告、小修、打折、发码不计；这些活动仍写诊断。游戏尚未公开14天或记录不全，用partial/not_applicable，不把“没经历14天”当0。

设最近一次有效更新公开日期为U，`post_update_baseline`比较U+2、U+3、U+4与U-5、U-4、U-3（相差7天），每个比较日均须覆盖合格。先每小时聚合，再对每组3天的小时值取中位数后求比。活动持续覆盖整个观察窗时标混杂；明显无法区分则partial。没有符合窗口的有效更新，null。

不得把这个数字叫“回流率”或认定是更新造成的因果增量。

## 5. 观察类指标也必须有固定档位

下列只允许0/25/50/75/100；填`status=observed`是“已观察后编码”，不是客观物理测量。报告注明人工/Agent编码。每一项至少有一个能定位的实际证据，宣传文案单独不支持评分；没有观察能力则unknown。

档位向下取最强已被证据支持的一档。多个维度可引用同一视频，但分别写出不同观察事实；不能同一“有抽卡”同时给所有项100。

### core_loop（8分权重）

0：实际观察显示无法进入核心玩法或循环持续断裂；这不是“没玩过”。
25：能开始动作，但目标/反馈不清、反复卡在同一步的证据明确。
50：可以展示一轮清楚的动作→反馈→奖励/失败→下一目标。
75：两次或两个独立观察中均能看见玩家顺畅完成并进入下一轮。
100：除75档，还能观察到短目标与中期目标衔接、主动再次尝试，而非仅宣称“上瘾”。

首奖励秒数作诊断；不强制所有类型一分钟内发奖励。

### replay_depth（8）

0：观察到内容结束后无可重复交互，且本次版本范围核实。
25：可重复，但只见同一动作与数值变化，尚无额外变化支撑。
50：至少观察到两种不同局势、目标、技巧路线或结果。
75：三种以上有实质区别的重复游玩情境，能指出为什么玩家改变行为。
100：除75档，跨局/跨日实际出现更进一步的技巧、合作、创作、探索或成长。

实体、职业、装备是可用证据，但UGC、随机场景、社交互动、竞速技巧同样可支撑。不奖励纯粹名字数量。

### design_difference（9）

先核对两款真实近似游戏。0：有证据表明主要交互完全复用且缺乏本次版本的可辨变化；25：主要是包装/题材变化；50：有一处实际改变玩法或玩家体验的差异；75：差异在完整核心循环中可反复观察；100：除75档，还有多个独立玩家/创作者围绕该差异产生不同玩法或内容。无参照或只有标题相似度，unknown。

这不等于法律上的抄袭判定，也不意味着模仿游戏一定不爆。

### decision_depth（8）

0：完整观察到关键决策均无结果差异；25：仅可识别简单选择但无法看见取舍；50：至少2种会改变结果的实际策略/技巧/选择；75：选择随阶段/队友/场景变化，至少2种不同约束下有取舍；100：能核实多个玩家实际试验、调整选择和复盘结果。

纯动作游戏的时机、路线、配合和技巧计入，不要求存在经济系统。记录`distinct_decision_types`作为证据摘要。

### community_participation（7）

0：有效观察中反复出现无法正常参与/合作的问题且无正面参与实例，需明确样本范围；25：1个独立玩家的真实选择/分享/合作实例；50：至少2个独立玩家参与；75：至少5个、覆盖2种参与形式；100：至少10个、覆盖3种形式且不止同一天/同一传播链。

形式包括提问、策略讨论、挑战、合作招募、作品分享、估值或UGC；数量只是冻结采样内的观察，不声称社区渗透率或留存。没找到玩家发言为unknown而不是0。

### shareable_moments（3）

0：实际材料不能形成可理解事件且玩家/创作者已明确反馈该问题；25：只有演示性瞬间，难以判断可重复；50：能定位一个普通玩家可复现/遇到的清晰瞬间；75：不同玩家有两类事件或同一事件不同结果；100：多个独立创作者已经采用这些事件做不同内容。

须给时间戳和事件说明；不是“我觉得它适合短视频”。大字标题、稀有掉落宣传不算实证。

## 6. 分数、覆盖与缺失界限

每项权重w_i，上表和档位得到s_i，0–100。

```text
K = 已观测/可计算项的权重之和          # 0..100
A = Σ(已知项 w_i × s_i / 100)          # 已知贡献，0..100
observed_subscore = 100 × A / K        # K>0，局部归一分
coverage = K / 100
score_bounds = [A, A + (100-K)]
```

界限表示未知项全为0或100时的理论上下界，**不是95%置信区间，不是爆款概率范围**。没有可用项时局部分null、界限[0,100]。

完整标题分`score`仅在K≥60、至少3组有证据且`ccu_g7`有效时提供；否则null，展示早期结构判断和界限。不把“只有玩法25分权重，局部95分”写成“爆款95分”。

分类：

- `HIGH_POTENTIAL`：标题分≥75、K≥80、六类来源均实际尝试。
- `WATCHLIST`：标题分≥60，或高分但证据不足以进入上一类。
- `LOW_PRIORITY`：标题分45–59.9。
- `WEAK_CURRENT_EVIDENCE`：标题分<45。
- `EARLY_CANDIDATE`：无可比总分，但C/D/V至少一组有≥65的已观察部分。
- `INSUFFICIENT_EVIDENCE`：不能给出有分量的潜力结论。
- `IDENTITY_UNRESOLVED`：对象都没确定，不评。

分类是研究优先级，不是买入、建站或投资决策。早期候选允许继续观察，不要求先到15个频道、3000 CCU或7天历史才入池。

`evidence_sufficiency=HIGH/MEDIUM/LOW`仅按K≥80/60/更低分档，必须和采集状态/来源质量/冲突一起展示。它不等于来源真实概率。

## 7. 反证、风险与适用限制

单日峰后跌70%不是通用失败标签；活动峰值分母容易误导，应看同星期日常基线是否仍抬升。本版不沿用“峰后必须留下50%”“更新峰必须高50%”的硬门槛。

付费推广、单主播、时区、节假日、儿童假期、相同开发群组协同宣发、多个来源复用同一数据、内容样本选择偏差均须披露。异常不等于作弊。

旧60样本的成功定义本来包含传播/搜索特征，存在结果选择与后见偏差，不能拿同一特征再证明自己的预测准确率。跨年份规模不同也需重做校准。

若用户要求采用新权重，另存新模型版本，保留旧输出；本轮不边看游戏边调整默认规则使它得高分。
